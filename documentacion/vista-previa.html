Proceso de adquisición de tecnología entre TI y Compras

Código TI-PRO-003 · Versión 1.1 · Diagrama: TI-PRO-003-Diagrama.drawio

Cliente interno Cliente externo TI Gerencia Compras

Regla de daño: si se daña un dispositivo de guardia, supervisor u otro cliente externo, la compra sigue el flujo externo. El usuario solicita directamente a Compras por correo, con el informe técnico de TI.

Definición de clientes

TipoQuiénes sonDóndeEquipos
Cliente interno Personal administrativo Quito y Guayaquil Laptops, PCs, monitores, accesorios
Cliente externo Clientes por fuera: guardias y supervisores Operación / campo Tablets y laptops

Los dos flujos

A. Cliente interno

  1. Ticket de necesidad o falla.
  2. TI evalúa. Si tiene arreglo o hay stock, repara o reasigna. No se compra.
  3. Si no tiene arreglo, TI elabora el informe y solicita la compra.
  4. Gerencia aprueba.
  5. Compras emite la orden y entrega el equipo a TI.
  6. TI prepara el equipo y lo entrega al usuario con acta.

B. Cliente externo

  1. Ticket (ejemplo: Tito indica que no le funciona el dispositivo).
  2. TI evalúa y emite informe técnico.
  3. El cliente solicita directamente a Compras por correo, con el informe de TI.
  4. Gerencia aprueba (igual que en el flujo interno).
  5. Compras entrega al usuario o envía correo.
  6. TI prepara el equipo y se habilita / entrega al usuario.

Pasos comunes después de la solicitud

  1. Gerencia revisa para la aprobación en ambos casos.
  2. Compras cotiza y emite la orden de compra.
  3. TI configura el equipo (sistema operativo, correo, seguridad, inventario).
  4. El usuario firma el acta de entrega y TI cierra el ticket.
